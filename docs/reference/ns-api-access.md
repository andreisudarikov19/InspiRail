# Access NS API products

InspiRail needs a subscription that includes the [NS-App Stations API](https://apiportal.ns.nl/api-details#api=nsapp-stations-api). To add a product to your profile:

1. Open [API Products](https://apiportal.ns.nl/products).

1. Click the product you need.

1. On the product page, under **Your subscriptions**, type a name for your subscription in the text field and click **Subscribe**.

    > The name of your app or website makes a good subscription name.

The new subscription appears on your [Profile](https://apiportal.ns.nl/profile) page, under **Abonnementen**. It includes:

* The subscription name
* The subscription start date
* A **Primary** and a **Secondary** API key

To check that a key works, see [Connection testing](ns-api.md#connection-testing).
