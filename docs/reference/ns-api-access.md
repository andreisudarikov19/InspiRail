# Access NS API products

To use NS API, add a product to your profile:

1. Open [API Products](https://apiportal.ns.nl/products).

1. Select the relevant API product and click it. 

1. On the product page, under **Your subscriptions**, in the text field, write the name of your subscription and click **Subscribe**.

    > It's useful to use the name of your app or website as a subscriuption name.

You'll see the new subscription on your [Profile](https://apiportal.ns.nl/profile) page under **Abonnementen**. It includes:

* Subscription name
* Subscriotion start date
* **Primary** and **Secondary** API keys
